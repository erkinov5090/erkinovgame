ERKINOV GAMES — Setup, VS Code & Netlify Guide

1. Opening & Running in VS Code

Save this file as index.html inside a folder named ERKINOV-GAMES. Open the folder in VS Code, install the Live Server extension, and click Go Live at the bottom right.

2. Deploying to Netlify

Go to app.netlify.com/drop and drag-and-drop your ERKINOV-GAMES folder directly into the browser window. Netlify will deploy the platform globally in seconds with HTTPS enabled.

3. Architecture & Storage

Powered by a zero-dependency HTML5 Canvas & DOM Engine, Web Audio procedural sound synthesizer, procedural SVG cover art generator, and persistent LocalStorage profiles.
